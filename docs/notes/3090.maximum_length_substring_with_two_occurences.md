# Maximum Length Substring With Two Occurrences

## Problem

- Name: Maximum Length Substring With Two Occurrences
- Difficulty: Easy
- Category: Sliding Window

## Core Pattern

### Main Algorithmic Pattern

Variable-size sliding window with a frequency map.

### Recognition Cues

Look for problems asking for:

- The longest substring/subarray.
- A frequency constraint on elements.
- "At most K occurrences" of each element.
- A contiguous range that must remain valid.
- The goal is to maximize the size of the valid range.

### Why the Pattern Applies

Adding a character to the right can make the current window invalid.

Because removing characters from the left can restore validity, we can maintain a dynamic window using two pointers.

Each character enters and leaves the window at most once, giving linear time.

## Intuition

Think of the window `[i, j]` as the largest valid substring ending at `j`.

When `s[j]` is added, only its frequency can cause a violation because the previous window was already valid.

If its frequency becomes greater than 2, move `i` forward until that frequency becomes at most 2 again.

Once the window is valid, its length is a candidate for the answer.

The important invariant is:

> Every window considered for `max_len` contains each character at most twice.

## Brute Force

### Idea

Consider every possible substring and count the frequency of each character.

Keep the longest substring where no character occurs more than twice.

### Complexity

- Time: O(n²) or worse depending on how frequencies are calculated.
- Space: O(k), where `k` is the number of distinct characters.

### Why It Is Inefficient

There are O(n²) possible substrings, while the sliding-window approach can process the entire string in O(n).

## Optimal Solution

### Key Observations

1. The substring must be contiguous.
2. Every character can appear at most twice.
3. When adding a character causes its frequency to become 3, the window becomes invalid.
4. Moving the left pointer restores validity.
5. Both pointers only move forward.

### Data Structures Used

- Two pointers:
  - `i`: left boundary.
  - `j`: right boundary.
- Frequency dictionary:
  - Stores the count of each character inside the current window.

### Algorithm Explanation

Expand the window by moving `j`.

Increment the frequency of `s[j]`.

If that character now occurs more than twice, move `i` forward while decrementing frequencies until the constraint is restored.

After the window becomes valid, update the maximum length.

## Algorithm

1. Initialize `i = 0`, `j = 0`.
2. Initialize an empty frequency map.
3. While `j` is inside the string:
   1. Add `s[j]` to the frequency map.
   2. If its frequency exceeds 2:
      - Remove characters from the left.
      - Increment `i`.
      - Continue until the frequency constraint is satisfied.
   3. Update the maximum window length.
   4. Increment `j`.
4. Return the maximum length.

## Complexity

### Time Complexity

O(n)

Both `i` and `j` move from left to right at most `n` times.

### Space Complexity

O(min(n, alphabet_size))

The frequency map stores the characters present in the window.

For a fixed character alphabet, this is effectively O(1).

## Edge Cases

- Empty string → 0.
- One character → 1.
- Two identical characters → 2.
- More than two identical characters → maximum remains 2.
- All characters distinct → entire string is valid.
- Multiple characters reaching frequency 3 at different positions.
- Repeated patterns such as `abcabcabc`.

## Alternative Approaches

### Brute Force

Enumerate substrings and validate their frequencies.

Simple but O(n²) or worse.

### Fixed-Size Frequency Array

If the input alphabet is known and small, a frequency array can replace the dictionary.

The algorithm remains the same.

### Sliding Window With a Violation Counter

Instead of repeatedly checking the frequency of `s[j]`, maintain information about whether any character exceeds the allowed frequency.

This is useful when the constraint becomes more complicated.

## Similar Problems

1. Longest Substring Without Repeating Characters
   - Sliding window with a character constraint.
   - Difference: each character may occur at most once.

2. Longest Substring with At Most K Distinct Characters
   - Sliding window.
   - Difference: constrains the number of distinct characters rather than each frequency.

3. Longest Repeating Character Replacement
   - Sliding window.
   - Difference: validity depends on the most frequent character and allowed replacements.

4. Length of Longest Subarray With At Most K Frequency
   - Very similar frequency-based sliding window.
   - Difference: the allowed frequency is parameterized by `K`.

5. Minimum Window Substring
   - Uses two pointers and frequency maps.
   - Difference: minimizes a window satisfying required frequencies instead of maximizing a valid window.

## Python Tips

- `dict.get(key, 0)` can simplify frequency updates.
- A `collections.Counter` can also maintain frequencies.
- A normal dictionary is sufficient and avoids unnecessary abstraction here.
- `max(current, candidate)` is useful for maintaining the answer concisely.

## Interview Discussion

### Why can the left pointer move only forward?

Once a left boundary becomes invalid or unnecessary, moving it backward cannot help maintain the maximum valid window efficiently.

### Why is the algorithm O(n) despite the nested while loop?

Although there is a nested loop, the left pointer never moves backward.

Across the entire execution, `i` can increase at most `n` times, and `j` can increase at most `n` times.

Therefore the total work is O(n).

### Could a frequency array be used?

Yes, if the character set is known and bounded.

### What changes if each character can occur at most K times?

Replace the fixed constraint `2` with `K`.

The same sliding-window structure works.

## Personal Takeaways

- "Longest valid substring" + frequency constraint is a strong sliding-window signal.
- Maintain an explicit window invariant.
- Expand with the right pointer and shrink with the left pointer when invalid.
- A nested `while` does not automatically mean O(n²); analyze pointer movement.
- When a constraint is violated by the newly added element, shrinking from the left can restore validity.
