2996. Missing Integer

Problem

Name: Missing Integer

Difficulty: Easy

Category: Array / Hash Set / Prefix Processing

Core Pattern

Sequential Prefix + Membership Lookup

Find the longest sequential prefix beginning at nums[0], calculate its sum, then find the smallest value starting from that sum that is absent from the array.

Intuition

For [3,4,5,1,2], the sequential prefix is [3,4,5], whose sum is 12. The answer is the first absent integer starting from 12.

The solution therefore has two independent phases:

Detect the sequential prefix.

Use hash-based membership to advance past values already present.

Algorithm

Build a membership structure containing all values.

Start seq_sum with nums[0].

Scan from index 1 while nums[i] == nums[i-1] + 1.

Add each prefix value to seq_sum.

While seq_sum exists in the membership structure, increment it.

Return seq_sum.

Complexity

Time: O(n) average case.

Space: O(n).

Code Review

Your solution is correct and optimal asymptotically.

The Counter is valid because x in counter performs dictionary-style membership lookup. However, frequencies are never used, so set(nums) communicates the intent better.

This special case is also unnecessary:

if len(nums) == 1:
    return nums[0] + 1

The general algorithm already handles a one-element array.

A slightly cleaner version is:

class Solution:
    def missingInteger(self, nums: list[int]) -> int:
        seen = set(nums)
        seq_sum = nums[0]

        for i in range(1, len(nums)):
            if nums[i] != nums[i - 1] + 1:
                break
            seq_sum += nums[i]

        while seq_sum in seen:
            seq_sum += 1

        return seq_sum

This is only a readability improvement; your submitted logic does not need a correction.

Edge Cases

[5] -> 6

[1,2,3,4] -> 10

[5,1,2,3] -> 6

If the prefix sum is absent, it is immediately the answer.

If several consecutive values starting at the prefix sum exist, the while loop skips them.

Alternative Approaches

set(nums): preferred when only membership is needed.

Sorting: works but costs O(n log n) and is unnecessary.

Interview Takeaways

Separate candidate generation from membership checking.

Use a set when frequencies are irrelevant.

Hash membership turns repeated scans into average O(1) checks.

Avoid special cases when the general algorithm already handles them.
