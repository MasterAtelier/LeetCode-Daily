# Check Divisibility by Digit Sum and Product

## Problem

- Name: Check Divisibility by Digit Sum and Product
- Difficulty: Easy
- Category: Math / Digit Manipulation

## Core Pattern

### Main Algorithmic Pattern

Digit extraction and accumulation.

### Recognition Cues

Look for problems that require:
- Processing every digit of an integer.
- Computing the sum or product of digits.
- Checking a property of the original number using those values.
- Repeatedly reducing a number using `% 10` and `// 10`.

### Why the Pattern Applies

The required values depend independently on every digit of `n`.

Each digit can be extracted using:

- `n % 10` → last digit
- `n // 10` → remove last digit

Therefore, a single traversal over the digits is sufficient.

## Intuition

Think of the number as a sequence of digits rather than as one mathematical value.

For every digit:

1. Extract it.
2. Add it to the digit sum.
3. Multiply it into the digit product.
4. Remove it from the number.

After all digits have been processed, calculate:

`digit_sum + digit_product`

and check whether the original number is divisible by that value.

The important interview insight is that there is no need to convert the number to a string. Arithmetic digit extraction gives an O(d) solution with O(1) extra space.

## Brute Force

### Idea

Convert the number to a string, iterate over its characters, convert each character back to an integer, and calculate the sum and product.

### Complexity

- Time: O(d)
- Space: O(d)

where `d` is the number of digits.

### Why It Is Less Efficient

The string representation requires additional memory proportional to the number of digits.

The arithmetic approach achieves the same O(d) time with O(1) auxiliary space.

## Optimal Solution

### Key Observations

1. The original value of `n` must be preserved because `n` is modified while extracting digits.
2. Every digit can be extracted using `% 10`.
3. Every processed digit can be removed using `// 10`.
4. The digit sum can be accumulated incrementally.
5. The digit product can also be accumulated incrementally.
6. Only one pass over the digits is necessary.

### Data Structures Used

No explicit data structure is required.

Only scalar variables are needed:

- Original number
- Digit sum
- Digit product
- Current digit

### Algorithm Explanation

Initialize:

- `digit_sum = 0`
- `digit_product = 1`
- Preserve the original number.

While the number is non-zero:

1. Extract the last digit.
2. Add the digit to `digit_sum`.
3. Multiply the digit into `digit_product`.
4. Remove the last digit.

Finally, calculate:

`digit_sum + digit_product`

and determine whether the original number is divisible by it.

## Algorithm

1. Store the original value of `n`.
2. Initialize the digit sum to `0`.
3. Initialize the digit product to `1`.
4. While `n` is non-zero:
   - Extract the last digit.
   - Add the digit to the sum.
   - Multiply the digit into the product.
   - Remove the last digit.
5. Add the digit sum and digit product.
6. Return whether the original number is divisible by this value.

## Complexity

Let `d` be the number of digits.

- Time Complexity: O(d)
- Space Complexity: O(1)

Each digit is processed exactly once.

## Edge Cases

- Single-digit numbers.
- Numbers containing zero.
- Numbers whose digit product becomes zero.
- Numbers where `digit_sum + digit_product` equals the original number.
- Numbers that are not divisible by the resulting value.

For example, when a number contains `0`, the digit product becomes `0`, after which it remains `0`.

## Alternative Approaches

### String-Based Digit Processing

Convert `n` to a string and iterate over the characters.

- Time: O(d)
- Space: O(d)

This is simpler syntactically but uses additional memory.

### Arithmetic Digit Processing

Use `% 10` and `// 10`.

- Time: O(d)
- Space: O(1)

This is the preferred solution because it directly exploits the mathematical structure of the problem.

## Python Tips

- `n % 10` extracts the last digit.
- `n // 10` removes the last digit.
- Avoid naming variables `sum`, `list`, `str`, or other Python built-ins when possible.
- Prefer `return condition` over `return True if condition else False`.

For example:

`return num % (digit_sum + digit_product) == 0`

is preferable to:

`return True if num % (digit_sum + digit_product) == 0 else False`

## Interview Discussion

### Why preserve the original number?

The working copy of `n` is repeatedly reduced using integer division. Therefore, the original value would otherwise be lost before the final divisibility check.

### Why initialize the product to 1?

Multiplication needs an identity value. Starting with `1` ensures the first digit is multiplied correctly.

### What happens if a digit is zero?

The product becomes zero. This is still valid because zero is a valid factor in the digit product.

### Can this be solved without converting the number to a string?

Yes. `% 10` and `// 10` allow every digit to be processed using O(1) auxiliary space.

### What is the complexity?

O(d) time and O(1) auxiliary space, where `d` is the number of digits.

## Personal Takeaways

1. Process integer digits with `% 10` and `// 10`.
2. Preserve the original number before destructively modifying it.
3. Use `0` as the identity for addition and `1` as the identity for multiplication.
4. Avoid unnecessary string conversion when arithmetic digit processing is sufficient.
5. Prefer `return condition` over a redundant ternary boolean expression.
