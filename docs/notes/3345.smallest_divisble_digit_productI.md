# 3345. Smallest Divisible Digit Product I

## Problem

- **Difficulty:** Easy
- **Category:** Brute Force, Math

## Core Pattern

**Brute Force Candidate Search**

### Recognition Cues

- Find the smallest/largest value satisfying a property.
- Constraints are small enough to check candidates sequentially.
- The property can be verified quickly.

### Why this pattern applies

The search space is tiny (`n ≤ 100`), so checking each number until one satisfies the digit-product divisibility condition is efficient.

## Intuition

Start from `n` and test each number. Since each test only requires computing the product of a few digits, brute force is sufficient.

## Brute Force

### Idea

- Compute the digit product.
- If divisible by `t`, return the number.
- Otherwise increment and repeat.

### Complexity

- Time: `O(k × d)`
- Space: `O(1)`

## Optimal Solution

The brute-force approach is already optimal for the given constraints.

## Algorithm

1. Start from `n`.
2. Compute the product of its digits.
3. If divisible by `t`, return it.
4. Otherwise increment `n`.
5. Repeat.

## Complexity

- Time: `O(k × d)`
- Space: `O(1)`

## Edge Cases

- Single-digit numbers.
- Numbers containing `0`.
- `t = 1`.
- `n = 100`.

## Alternative Approaches

No approach significantly improves on brute force for these constraints.
